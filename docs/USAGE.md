# 使用说明

## 开始使用

1. 将 V9 Turbo+ 的 2.4G 接收器连接电脑，并确认 Windows 可以分别选择耳机和备用扬声器。
2. 下载发布版 ZIP，解压到一个可以写入、准备长期保留的文件夹。
3. 双击 `V9自动声音切换.exe`。程序在通知区域显示耳机图标，不打开常驻主窗口。
4. 双击托盘图标打开设置，选择耳机输出和备用扬声器输出。两项必须是不同设备。
5. 勾选“启用自动声音切换”和“登录 Windows 后自动运行”，点击保存。

耳机连接时通常约 1 秒内识别；放回底座、耳机关闭并停止回复状态查询后，通常约 3～4 秒切回备用扬声器。无线连接建立和驱动处理也会影响时间。

## 托盘操作

右键耳机图标可查看状态和电量、暂停或恢复自动切换、开关登录自启动、打开设置、查看日志和退出。图标可能藏在任务栏的隐藏图标菜单中。

暂停状态会保存，下次登录仍然暂停。退出只停止这一次运行；如果登录自启动仍然开启，下次登录会再次运行。切换不会更改耳机、扬声器原有音量，也不会切换麦克风。

在同一耳机状态下，程序不会持续抢回你手动选择的输出；下一次耳机在线/离线切换、恢复自动切换或保存设备设置时，会重新应用对应输出。

## 自启动与移动目录

程序只为当前 Windows 用户写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中名为 `V9TurboAutoAudio` 的启动项，内容为带引号的程序完整路径，无需管理员权限。

请保留程序文件夹。若移动目录，先关闭自启动并退出，移动后重新运行并开启自启动。Windows 任务管理器中的“启动应用”也可以禁用该启动项；如果那里被禁用，仅勾选程序内的开关未必能恢复，请在任务管理器重新启用。

## 本地文件

运行后在程序目录自动生成：

| 文件 | 内容 |
| --- | --- |
| `设置.json` | 自动切换开关和这台电脑的输出设备编号/名称 |
| `运行状态.json` | 最近状态、默认输出、进程和错误信息 |
| `运行日志.txt` | 状态变化和切换结果 |
| `运行日志.txt.1` | 上一次轮转日志，日志到达约 512 KB 时保留一份 |

这些文件只保存在本机，不随发布包分发。不要把它们上传到公开问题或仓库；排查问题时可以仅摘录相关错误，去掉设备编号和本机路径。

一般不需要手工编辑配置；`settings.example.json` 只用于说明格式，建议通过托盘设置选设备。

## 常见情况

**系统输出已切换，某个应用仍然没有声音：**检查应用自己的输出设置，选择“系统默认”。部分应用需要重新建立播放或通话会话。

**未找到备用扬声器：**确保设备连接且可用，打开设置选择实际输出。备用设备不必是 Realtek。

**读状态错误：**程序保留当前输出并重试；打开日志查看原因。厂商工具和其他程序同时操作 HID 接口可能影响状态读取，可退出它们后重试。

**离线状态：**放回底座、手动关机、切换蓝牙和离开接收器范围都可能表现为离线。拔掉接收器也会切向备用扬声器。

**需要停用或卸载：**右键图标关闭“登录后自动启动”，然后退出。程序退出后可删除解压文件夹；没有服务、计划任务或后台网络组件。
